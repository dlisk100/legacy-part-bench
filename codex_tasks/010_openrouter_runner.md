# Codex Task 010 — OpenRouter Runner

Implement OpenRouter model calling, response storage, caching, and one-model run script.

## Requirements

- read `OPENROUTER_API_KEY`
- support text prompt
- support optional image input
- cache by run key
- save raw response
- parse code
- execute code
- score result

## Acceptance criteria

One command can run one model on one benchmark item and produce a scorecard.
