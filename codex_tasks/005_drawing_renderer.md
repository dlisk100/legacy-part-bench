# Codex Task 005 — Drawing Renderer

Implement a simple readable drawing renderer for mounting plates.

## Requirements

Generate `drawing.png` with:

- top view outline
- hole circles
- overall length dimension
- overall width dimension
- thickness note
- hole diameter callout
- hole center coordinates or dimensions from edges
- units: mm

It does not need perfect ASME compliance.

## Acceptance criteria

Every generated dataset item has a readable `drawing.png`.
